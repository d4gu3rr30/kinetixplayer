# Kinetix

Адаптивный музыкальный плеер на TypeScript, React и Node.js. Устанавливается как PWA на телефоне и компьютере.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173. Поиск и страницы жанров работают без ключей через [Openverse](https://openverse.org/) и открытые записи [Internet Archive](https://archive.org/): полные треки и обложки доступны там, где их отдают источники. Deezer показывает популярные релизы как 30-секундные превью. Прямая ссылка на публичный трек SoundCloud и импорт собственных аудиофайлов также доступны. Раздел «Каталоги» собирает популярных исполнителей и подборки из YouTube через `yt-dlp`; Яндекс Музыка и ВКонтакте подключаются токенами (см. ниже).

В PowerShell из другой папки:

```powershell
cd 'C:\Users\XXX\Documents\Codex projects\kinetixplayer'
npm install # только при первом запуске
npm run dev
```

Оставьте это окно открытым, пока слушаете музыку. Для остановки нажмите `Ctrl+C`. После изменения `.env` перезапустите сервер той же командой.

Для поиска по каталогу SoundCloud и обнаружения клипов скопируйте `.env.example` в `.env` и добавьте:

```text
SOUNDCLOUD_CLIENT_ID=...
SOUNDCLOUD_CLIENT_SECRET=...
YOUTUBE_API_KEY=...
GOOGLE_CLIENT_ID=...
YANDEX_MUSIC_TOKEN=...
VK_ACCESS_TOKEN=...
```

Серверные ключи остаются на сервере. `GOOGLE_CLIENT_ID` — публичный идентификатор бесплатного веб-клиента OAuth 2.0 из [Google Cloud Console](https://console.cloud.google.com/apis/credentials); добавьте разрешённые JavaScript origins `http://localhost:5173` и адрес развернутого сайта. Сервер проверяет ID token по официальной библиотеке Google. Для SoundCloud требуется зарегистрированное приложение и, по [текущим правилам](https://developers.soundcloud.com/docs/api/register-app.html), Artist Pro. YouTube Data API используется только для поиска клипа и открытия его на YouTube. Ключи SoundCloud включают блок недавних треков выбранных исполнителей.

### Каталоги популярной музыки

Раздел «Каталоги» и источник «YouTube» работают через локальный [yt-dlp](https://github.com/yt-dlp/yt-dlp): сервер ищет трек, извлекает аудиопоток и проксирует его в плеер без видео. Установите yt-dlp и перезапустите сервер:

```bash
winget install yt-dlp
# или
python -m pip install -U yt-dlp
```

Если бинарник не в `PATH`, задайте `YTDLP_PATH`. Ключи для YouTube не нужны; `YOUTUBE_API_KEY` по-прежнему используется только для поиска клипов.

Начиная с версии 2025.11 yt-dlp использует JavaScript-рантайм для обхода защиты YouTube. Сервер передаёт `--js-runtimes node` (Node.js уже установлен вместе с проектом). Другой рантайм можно указать в `YTDLP_JS_RUNTIME`, отключить — значением `none`, но тогда часть видео будет недоступна.

Некоторые ролики YouTube требуют авторизацию («Sign in to confirm you're not a bot») или возрастной доступ. Для них экспортируйте cookies браузера в Netscape-формате и задайте `YTDLP_COOKIES=C:\path\to\cookies.txt`. Альтернатива — `YTDLP_COOKIES_FROM_BROWSER=chrome|edge|firefox`, но на Windows браузер должен быть закрыт, иначе yt-dlp не сможет скопировать базу cookies. Cookies остаются на сервере и не отправляются клиенту.

Сервер кэширует подписанные ссылки на поток, повторно извлекает их при истечении или ошибке CDN и прогревает следующий трек заранее, поэтому повторные запуски и переключения идут быстрее. Если конкретное видео удалено, закрыто по региону или правообладатель запретил встраивание, источник вернёт ошибку — выберите другой трек или источник.

Яндекс Музыка работает без ключей в режиме 30-секундных превью. Для полного воспроизведения добавьте `YANDEX_MUSIC_TOKEN` — свой OAuth-токен из запросов веб-клиента Яндекс Музыки (DevTools → Network → заголовок `Authorization: OAuth ...`). Токен остаётся на сервере.

ВКонтакте подключается через `VK_ACCESS_TOKEN` с доступом к аудио. Поиск использует `audio.search`, а прямые ссылки на MP3 проходят через серверный прокси и действуют ограниченное время. Без токена источник скрыт. SoundCloud с ключами `SOUNDCLOUD_CLIENT_ID` и `SOUNDCLOUD_CLIENT_SECRET` появляется отдельным источником в поиске.

## Production

```bash
npm run build
npm run preview
```

Сервер откроется на http://localhost:8787. Для установки PWA в обычном браузере production-развёртывание должно работать через HTTPS (localhost — исключение). Сервис-воркер кэширует интерфейс; собственные аудиофайлы хранятся в IndexedDB на устройстве. Браузер может удалить локальные данные при очистке хранилища.

Аккаунты и «Моменты» сохраняются сервером в `.data/users.json` (путь можно задать через `KINETIX_DATA_FILE`). Для реального развёртывания нужны HTTPS и постоянное серверное хранилище с резервным копированием. Пароли хешируются через scrypt; сессии используют HttpOnly cookie. Проверка сценариев аккаунта: `npm run test:accounts`.

## Возможности

- Потоковое воспроизведение публичных треков через официальный виджет SoundCloud, с атрибуцией источника.
- Каталоги популярных исполнителей и подборок (KAMZ0NER, Кишлак, ushira и другие) с полными треками из YouTube через yt-dlp; Яндекс Музыка и ВКонтакте подключаются токенами.
- Поиск полных записей Openverse и лицензированных MP3 из Internet Archive без ключей, с обложками и ссылкой на запись и лицензию. В поиске можно выбрать один каталог или общую выдачу. Deezer показывает 30-секундные превью. Поиск SoundCloud через серверный OAuth Client Credentials при наличии ключей.
- Синхронные строки LRCLIB, переход к строке нажатием, обычный текст как запасной вариант.
- Оффлайн-библиотека собственных аудиофайлов и скачанных лицензированных записей Internet Archive; файлы хранятся на устройстве в IndexedDB.
- Ссылка на клип только при достаточно точном совпадении в YouTube Data API и наличии ключа.
- Адаптивный интерфейс, оформленная медиатека с переходом из боковой панели, повтор, громкость, предоставленные пользователем логотип и иконка и отключаемый в настройках мини-плеера визуализатор (по умолчанию включён).
- Регистрация и вход, профиль с именем, статусом и аватаром, анимированная панель профиля и его настроек, сохранение нескольких строк песни в оформленный «Момент» с обложкой и данными трека.
- Вход через Google после добавления OAuth Client ID; полноэкранная карта исполнителей с поиском и постраничной загрузкой фотографий из Wikipedia. Карту можно двигать мышью или касанием, переключить на список с сортировкой, пропустить при регистрации и открыть снова в профиле. На главной при наличии ключей SoundCloud видны недавние треки выбранных артистов.
- Двенадцать жанров на главной, каждый открывает страницу с доступными треками Internet Archive.

## Ограничения источников

SoundCloud [запрещает приложениям оффлайн-доступ к пользовательскому контенту](https://developers.soundcloud.com/docs/api/terms-of-use), даже если на платформе трек доступен для скачивания. [Правила YouTube API](https://developers.google.com/youtube/terms/developer-policies) также запрещают оффлайн-копии и выделение аудио из видео. [Jamendo API](https://devportal.jamendo.com/api_terms_of_use) запрещает специально разработанный оффлайн-доступ, поэтому Kinetix использует Openverse для онлайн-воспроизведения и сохраняет оффлайн только собственные файлы пользователя и записи Internet Archive с лицензией Creative Commons. Перед повторным использованием записи следует проверить её условия на странице источника. Открытый каталог содержит независимые и архивные записи и не гарантирует наличие каждого коммерческого релиза. Фотографии артистов берутся из Wikipedia / Wikimedia Commons; права и авторство конкретного фото указаны на странице источника. Каталоги загружают аудио через yt-dlp, а Яндекс Музыка и ВКонтакте используют токены пользователя; такие способы могут нарушать условия сервисов и права правообладателей. Используйте их только для контента, на который у вас есть права, и на свой риск. Треки YouTube, Яндекс Музыки и ВКонтакте не сохраняются для оффлайна.
